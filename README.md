# digital-business-card
digital business card Afik Oz

אתר כרטיס ביקור אישי ועסקי המציג את הרקע המקצועי, הניסיון ופרטי הקשר, נבנה כחלק ממטלה אקדמית[cite: 1].

## 🚀 תכונות האתר
* **פרופיל מקצועי:** מציג תפקיד, תיאור רקע מקצועי, וכישורים טכניים.
* **מצב כהה / בהיר (Dark/Light Mode):** מנגנון מעבר בין ערכות צבעים המבוסס על HTML ו-CSS בלבד (ללא שימוש ב-JavaScript)[cite: 1].
* **רספונסיביות מלאה:** מותאם באופן מושלם לצפייה במסכי מחשב, טאבלטים ומכשירי מובייל[cite: 1].
* **תקנים טכניים:** קוד נקי ותקני, הפרדה מלאה לקובץ עיצוב חיצוני (`style.css`), ושימוש ב-HTML5 ו-CSS3[cite: 1].

## 🛠️ טכנולוגיות
* **HTML5**
* **CSS3** (כולל משתנים דינמיים ו-Media Queries)

## 📂 מבנה הפרויקט
```text
├── index.html    # מבנה ה-HTML של כרטיס הביקור
└── style.css     # עיצוב האתר, תמיכה ברספונסיביות ומצב כהה/בהיר
